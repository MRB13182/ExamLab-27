# HSC 2027 AI Exam Lab

A mobile-first Next.js starter for chapter-wise HSC practice exams using the official Google GenAI JavaScript SDK. Includes CQ/MCQ generation, countdown timer, auto-submit, server-side MCQ marking, AI-assisted CQ grading, answer-sheet image upload, and browser-local result history.

## Requirements

- Node.js 20.9+ (Node 22 recommended)
- A Gemini API key from Google AI Studio: https://aistudio.google.com/apikey

## Run locally

1. Extract this folder.
2. Open a terminal in the project directory.
3. Install packages:

   ```bash
   npm install
   ```

4. Copy `.env.example` to `.env.local`.
5. Put your key in `.env.local`:

   ```env
   GEMINI_API_KEY=your_real_key_here
   GEMINI_MODEL=gemini-2.5-flash
   ```

6. Start the dev server:

   ```bash
   npm run dev
   ```

7. Open http://localhost:3000.

Do not share `.env.local`, commit it to Git, or put the key in a `NEXT_PUBLIC_` variable. Restart the server after changing environment variables.

## Current MVP scope and limitations

- Questions are generated by Gemini based on the selected subject/chapter and board-style instructions. The current build does not independently search and verify the official NCTB syllabus or past board papers; add Gemini Google Search grounding and source-citation display as a follow-up feature if you need online research for each test.
- The server stores the private answer key in process memory for local development. Restarting the server loses active exam sessions. Before public/serverless deployment, replace `lib/exam-store.js` with persistent server-side storage (for example, Supabase) and add authentication/ownership rules.
- Result history is stored in this browser's localStorage. It is not synced between devices and can be cleared by the user.
- The timer auto-submits while the page is open. Browser sleep, device shutdown, network loss, or closing the page can delay submission. Production-grade timing needs a server-recorded start/deadline in a persistent database.
- MCQ marking is deterministic. CQ marking and image OCR are AI-assisted estimates, not official marks. Review them critically.
- Screenshot blocking is not included because websites cannot reliably prevent screenshots or photos from another device.
- Add rate limiting, authentication, usage controls, request-size limits, and persistent storage before exposing the app publicly.
